Flagship Project

DreOS — Personal Intelligence Platform

Active · Phase 12 Complete

An autonomous AI agent that monitors my portfolio and alerts me — without being asked.

DreOS started as a weekend market tracker and grew into a 15-phase AI platform with real-time data pipelines, a Flask web app, a ReAct reasoning loop, and proactive monitoring running every 30 minutes.

The Problem

I wanted to understand how production AI systems actually work — not by reading about them, but by building one. I set a goal: a personal intelligence platform that monitors 25 financial assets, reads the news, manages my projects, and runs autonomously. No tutorials. Just build.

What I Built

A 15-phase platform spanning data ingestion, AI analysis, web delivery, and autonomous agents. Live prices for 25 assets, cross-referenced news headlines, Jira and Figma monitoring, AI-written morning briefs, PDF reports, and a ReAct loop where Groq's LLM autonomously decides which tools to call.

How the Agent Thinks

Given a plain-English goal, the agent reasons about what it needs, calls the right tools, observes the results, and reasons again — without hardcoded logic. Every step is logged to agent_log.json.

Outcome

Fully operational, running daily. Proactive alerts when any asset moves more than 5%. AI-written briefs delivered every morning. ReAct agent chaining tools autonomously. 90-day price history growing in SQLite.
